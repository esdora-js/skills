# Migration Checklist

Use after classification to move from source docs to AI governance.

## Before Migration

- Source docs inventoried.
- Each extracted item has source evidence.
- Conflicts and stale docs are flagged.
- Every item has a category.
- Universal and domain-specific scopes are separated.

## During Migration

- Rules are rewritten as verifiable obligations.
- Workflows are step-based and task-scoped.
- References keep source links and do not become mandatory constraints.
- Skill candidates have distinct trigger language and task boundaries.
- Temporary, secret, duplicated, and source-only content is excluded.

## After Migration

- Normal AI development can find required rules without reading all docs.
- Task-specific workflows load only relevant references.
- No single output file becomes a docs dump.
- Validation checks exist for the highest-risk rules.
- Archived source artifacts are clearly marked as legacy or source-only.
