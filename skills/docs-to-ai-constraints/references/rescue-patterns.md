# Rescue Patterns

## Oversized Skill Symptoms

- `SKILL.md` contains full docs instead of routing.
- Always Read includes too many files.
- Background, rules, workflows, and source excerpts are mixed together.
- The skill triggers for almost every project task.
- Agents must read the old large skill even for narrow tasks.

## Rescue Moves

- Freeze the old skill first; use it as source material.
- Create a classification table before moving files.
- Delete or archive source-only and stale content from the target design.
- Split by task boundary, not by original document folder.
- Keep one router only if there is a coherent shared domain.
- Make each new skill or workflow prove its trigger language.

## Do Not Do

- Do not wrap the same large content in more folders.
- Do not split mechanically by document filename.
- Do not keep the old skill as an Always Read dependency.
- Do not promote every section into a rule.
