# Classify Content

Use this workflow when the user asks whether something should be a rule, workflow, reference, memory candidate, or skill.

## Steps

1. Read the source excerpt or document section.
2. Identify the action expected from the AI agent.
3. Apply the category tests in `rules/classification-principles.md`.
4. Choose exactly one primary category and optional secondary category.
5. Recommend a destination and explain why.
6. If the item is a skill candidate, name the trigger language and recurring task boundary.
7. If the item is a rule, rewrite it into verifiable form.

## Output

Use this compact form:

| Source | Extracted item | Primary category | Destination | Rationale | Rewrite / next action |
|---|---|---|---|---|---|
