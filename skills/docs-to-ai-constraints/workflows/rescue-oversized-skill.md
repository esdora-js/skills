# Rescue Oversized Skill

Use this workflow when docs were already converted into one large skill.

## Steps

1. Freeze the oversized skill as a source artifact. Do not add more content to it.
2. Inventory its files and sections.
3. Classify each item using `references/classification-matrix.md`.
4. Remove source-only, stale, duplicated, secret, and temporary content from the target design.
5. Extract mandatory obligations into rules.
6. Extract repeated procedures into workflows.
7. Split true recurring capabilities into separate skill candidates.
8. Move background context into references.
9. Replace the oversized skill with a small router or archive it if no single coherent capability remains.
10. Validate that no generated target requires reading the old large skill for normal tasks.

## Output

Return:

1. Rescue diagnosis.
2. Content classification table.
3. Proposed split or archive plan.
4. New target layout.
5. Old-skill deprecation plan.
6. Validation checklist.
